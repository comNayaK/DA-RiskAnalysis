(2) Explanation of Pop 2 Count & Default Discrepancies (The 'Chimera' 999)
================================================================================
The 999 figure in Script 8 was a chimera! It added Pop 1 defaults from the active 201812 snapshot (646 defaults) to Pop 2 defaults from an un-bounded event table (353 defaults).
The event table (used directly in Script 8 for Pop 2) included loans that were modified or defaulted before 201812, but had subsequently paid off or zeroed out BEFORE the 201812 snapshot. When restricted to the true active 201812 snapshot, Pop 2 dropped from ~2,975 to 1,974 active loans, and its actual defaults dropped from 353 to 266.
The 266 actual defaults in Pop 2 break down by state: Current (55), 30_DPD (34), 60_DPD (58), and Modified (119). Script 9 missed the 119 Modified defaults because it only looped over Current, 30_DPD, 60_DPD.
Total valid snapshot actuals = 646 (Pop 1) + 266 (Pop 2) = 912 defaults. This perfectly reconciles everything.
